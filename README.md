# VulaTrade MVP

**VulaTrade — Start local. Sell smarter. Grow stronger.**

This is the first working frontend MVP for the VulaTrade business operating system.

## Current MVP features

- Landing page
- Dashboard
- Business setup
- Product/service setup
- Business page preview
- Customer tracker
- WhatsApp message templates
- Growth tools
- Learn / Get Paid toolkit

## Run locally

```bash
npm install
npm run dev
```
